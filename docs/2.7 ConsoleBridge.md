## 2.7 ConsoleBridge (`console`)

A `ConsoleBridge` atua como um canal de depuração e diagnóstico para os micro-apps. Como o código JavaScript executado dentro de um contêiner `WebView` isolado não exibe seus logs diretamente no terminal nativo, esta ponte intercepta as chamadas de log do micro-app e as redireciona formatadas para o console do React Native / Metro Bundler.

---

### Isenção de Permissões e Modelo Fire-and-Forget

1. **Acesso Livre:** O módulo `console` é o único que **não requer concessão prévia de permissões** no Helper (`MODULE_TO_PERMISSION_KEY`). Por se tratar de uma utilidade exclusiva de diagnóstico, ele permanece sempre liberado para uso de qualquer micro-app.
2. **Execução Assíncrona e Callback Seguro:** O envio de mensagens de log opera primordialmente no modelo _fire-and-forget_ (dispare e esqueça). No entanto, caso a requisição envie um `callbackId`, a ponte devolve uma confirmação simples (`{ success: true }`) para evitar que chamadas baseadas em _Promises_ na WebView fiquem pendentes.
3. **Formatação para o Metro Bundler:** As mensagens recebidas são enriquecidas com um carimbo de data/hora (`toLocaleTimeString`), indicação do nível do log (`[WebView-INFO]`, `[WebView-WARN]`, `[WebView-ERROR]`) e formatação indentada (`JSON.stringify(data, null, 2)`) para facilitar a leitura de objetos e arrays no terminal.

---

### Ações Disponíveis (`actions`)

---

#### 1. `LOG`

Redireciona uma mensagem de diagnóstico e seus dados associados para o console nativo do aplicativo hospedeiro.

- **O que faz:** Processa o nível do log, formata os parâmetros e aciona a função de console correspondente do React Native (`console.log`, `console.warn` ou `console.error`).
- **Parâmetros Esperados (`payload`):**
- `level` _(String, Opcional)_: Nível de severidade do log (`"info"`, `"log"`, `"warn"` ou `"error"`). Padrão: `"info"`.
- `message` _(String, Opcional)_: Texto descritivo do log.
- `data` _(Any, Opcional)_: Objeto, array ou valor primitivo adicional a ser exibido de forma estruturada.

```json
// Envio
{
  "module": "console",
  "action": "LOG",
  "level": "warn",
  "message": "Atenção: Uso de memória acima do esperado",
  "data": {
    "usageMB": 42.5,
    "limitMB": 50
  },
  "callbackId": "console_req_01"
}
```

- **Saída Gerada no Terminal Nativo (Metro):**

```text
[WebView-WARN] [21:35:25]: Atenção: Uso de memória acima do esperado {
  "usageMB": 42.5,
  "limitMB": 50
}

```

- **Retorno para a WebView (Apenas se um `callbackId` for fornecido):**

```json
{
  "callbackId": "console_req_01",
  "success": true
}
```

---

### Estrutura de Retorno em Caso de Erro

Se o micro-app tentar acionar uma ação desconhecida no `ConsoleBridge` (diferente de `LOG`) e fornecer um `callbackId`, a ponte responderá com o seguinte erro:

```json
{
  "callbackId": "console_req_01",
  "success": false,
  "error": "Ação 'AÇÃO_INVALIDA' não reconhecida no ConsoleBridge."
}
```
