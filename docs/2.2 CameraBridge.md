## 2.2 CameraBridge (`camera`)

A `CameraBridge` permite que o micro-app interaja com o hardware de captura de vídeo e foto do dispositivo usando a biblioteca `react-native-vision-camera`. Ela oferece suporte a captura de fotos de alta qualidade, alternância entre câmeras frontal/traseira e _streaming_ contínuo de quadros em tempo real (frames em Base64) para a WebView.

---

### Funcionamento Interno e Otimizações de Recursos

1. **Ativação sob Demanda:** Ao contrário de abordagens que solicitam permissões nativas na montagem do componente, o `CameraBridge` valida e solicita acesso à câmera **apenas quando o micro-app dispara uma ação** (`START_STREAM` ou `TAKE_PHOTO`).
2. **Ciclo de Streaming Otimizado (5 FPS):** Para o envio de vídeo ao micro-app, a ponte utiliza um loop controlado por intervalo (200ms) executando `takeSnapshot` em baixa resolução (640x480).
3. **Gerenciamento Seguro de Arquivos Temporários:** Tanto no streaming quanto na captura pontual, cada imagem gerada no armazenamento temporário do dispositivo é convertida para Base64 e imediatamente removida (`RNFS.unlink`), evitando o acúmulo de arquivos residuais e o esgotamento do disco.
4. **Renderização Oculta:** O elemento de pré-visualização nativo é posicionado fora do campo de visão visível (`left: -1000`, `opacity: 0`), permitindo que a captura de quadros ocorra em segundo plano enquanto a interface do micro-app sobrepõe a tela.

---

### Ações Disponíveis (`actions`)

---

#### 1. `START_STREAM`

Ativa a câmera nativa e inicia o envio contínuo de quadros (frames) codificados em Base64 para a WebView.

- **O que faz:** Solicita permissão nativa de câmera (se necessário), define o sensor ativo (`front` ou `back`), ativa o preview e inicia o temporizador de disparo de `FRAME`.
- **Parâmetros Esperados (`params`):**
- `position` _(String, Opcional)_: Posição inicial da câmera (`"back"` ou `"front"`). Padrão: `"back"`.

```json
// Envio
{
  "module": "camera",
  "action": "START_STREAM",
  "params": {
    "position": "back"
  },
  "callbackId": "stream_start_01"
}
```

- **Retorno Imediato de Confirmação (`sendToWebView`):**

```json
{
  "callbackId": "stream_start_01",
  "success": true,
  "message": "Stream iniciada"
}
```

- **Retorno Contínuo de Quadros (Evento Recorrente a cada 200ms):**

```json
{
  "module": "camera",
  "type": "FRAME",
  "data": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD..."
}
```

---

#### 2. `STOP_STREAM`

Paralisa a captura contínua de quadros e desativa o sensor de câmera para poupar bateria e processamento.

- **O que faz:** Interrompe o temporizador do loop de frames e define a câmera como inativa (`isActive = false`).
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "camera",
  "action": "STOP_STREAM",
  "params": {},
  "callbackId": "stream_stop_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "stream_stop_01",
  "success": true,
  "message": "Stream parada"
}
```

---

#### 3. `TAKE_PHOTO`

Captura uma foto em alta resolução utilizando as configurações ativas do sensor.

- **O que faz:** Captura a imagem, salva opcionalmente na galeria de fotos do dispositivo via `CameraRoll`, converte o arquivo para a Data URI Base64 e remove o arquivo temporário gerado pelo sistema.
- **Pré-requisito:** A câmera precisa estar previamente ativada via `START_STREAM`.
- **Parâmetros Esperados (`params`):**
- `flash` _(String, Opcional)_: Modo de flash (`"off"`, `"on"`, `"auto"`). Padrão: `"off"`.
- `saveToGallery` _(Boolean, Opcional)_: Define se a foto capturada deve ser persistida na galeria do celular. Padrão: `true`.

```json
// Envio
{
  "module": "camera",
  "action": "TAKE_PHOTO",
  "params": {
    "flash": "off",
    "saveToGallery": true
  },
  "callbackId": "photo_take_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "photo_take_01",
  "module": "camera",
  "type": "PHOTO_RESULT",
  "success": true,
  "data": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD..."
}
```

---

#### 4. `SWITCH_CAMERA`

Inverte o sensor de câmera utilizado no momento (`back` para `front` e vice-versa).

- **O que faz:** Calcula de forma síncrona o próximo estado da câmera, atualiza o sensor nativo em execução e devolve a nova posição confirmada.
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "camera",
  "action": "SWITCH_CAMERA",
  "params": {},
  "callbackId": "switch_cam_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "switch_cam_01",
  "success": true,
  "position": "front"
}
```

---

### Estrutura de Retorno em Caso de Erro

Se a permissão for negada no sistema operacional, a câmera estiver inativa no momento do disparo da foto ou ocorrer uma falha técnica de E/S, a resposta será enviada no seguinte formato:

```json
{
  "callbackId": "photo_take_01",
  "module": "camera",
  "type": "ERROR",
  "success": false,
  "error": "A câmera precisa estar ativa para capturar uma foto."
}
```
