## 2.5 FileBridge (`file`)

A `FileBridge` permite que os micro-apps gerenciem o sistema de arquivos local do dispositivo de forma segura e isolada. Ela fornece capacidades de leitura, escrita, listagem, seleção de documentos via seletor do sistema operativo e importação de mídias/arquivos do usuário, convertendo conteúdos para codificações compatíveis com a Web (`Base64` ou `UTF-8`).

---

### Proteções de Segurança e Isolamento do Sistema de Arquivos

1. **Prevenção contra Path Traversal (CWE-22):** Todos os nomes de arquivos e identificadores passam pela validação `isSafePathSegment`. É proibido o uso de delimitadores de caminho (`/`, `\`) e sequências de navegação (`..`), impedindo que um micro-app malicioso escape do seu diretório privado para acessar arquivos do sistema ou de outros módulos.
2. **Isolamento de Dados do Módulo (`data/` vs `code/`):** O código-fonte estático extraído do pacote do módulo reside no diretório `apps/{appId}/code`, enquanto os arquivos manipulados via `FileBridge` são gravados estritamente na pasta irmã `apps/{appId}/data`. Isso garante que atualizações ou reinstalações do micro-app preservem intactos os dados salvos pelo usuário.
3. **Cópia e Validação de Cache Local:** Ao selecionar arquivos do dispositivo via `PICK_FILE`, o Android frequentemente fornece URIs temporárias baseadas em `content://`. O Helper utiliza a função `keepLocalCopy` para transferir o conteúdo diretamente para a pasta de cache privada (`CachesDirectoryPath`), validando se o arquivo está contido dentro dos limites do aplicativo antes de efetuar a leitura em Base64 e remover o arquivo temporário.

---

### Ações Disponíveis (`actions`)

---

#### 1. `SAVE_FILE`

Grava um novo arquivo ou sobrescreve um existente no armazenamento isolado (`data/`) do micro-app.

- **O que faz:** Valida a segurança do nome do arquivo, cria o diretório isolado do aplicativo caso não exista e grava o conteúdo informado em disco.
- **Parâmetros Esperados (`params`):**
- `fileName` _(String, Obrigatório)_: Nome simples do arquivo (ex: `"config.json"`, `"relatorio.txt"`).
- `data` _(String, Obrigatório)_: Conteúdo a ser gravado no arquivo (em texto ou string Base64).
- `encoding` _(String, Opcional)_: Codificação do dado fornecido (`"base64"` ou `"utf8"`). Padrão: `"base64"`.

```json
// Envio
{
  "module": "file",
  "action": "SAVE_FILE",
  "params": {
    "fileName": "notas.txt",
    "data": "Conteudo em texto plano para teste",
    "encoding": "utf8"
  },
  "callbackId": "file_save_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "file_save_01",
  "module": "file",
  "type": "FILE_SUCCESS",
  "success": true,
  "message": "Arquivo salvo: notas.txt"
}
```

---

#### 2. `READ_FILE`

Lê um arquivo existente na pasta de dados privada do micro-app e devolve seu conteúdo para a WebView.

- **O que faz:** Verifica o caminho isolado do arquivo, realiza a leitura no formato especificado (`utf8` ou `base64`) e envia o resultado de volta ao micro-app.
- **Parâmetros Esperados (`params`):**
- `fileName` _(String, Obrigatório)_: Nome do arquivo presente no diretório `data/`.
- `encoding` _(String, Opcional)_: Formato em que o dado deve ser lido (`"base64"` ou `"utf8"`). Padrão: `"base64"`.

```json
// Envio
{
  "module": "file",
  "action": "READ_FILE",
  "params": {
    "fileName": "notas.txt",
    "encoding": "utf8"
  },
  "callbackId": "file_read_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "file_read_01",
  "module": "file",
  "type": "FILE_DATA",
  "success": true,
  "data": "Conteudo em texto plano para teste",
  "fileName": "notas.txt"
}
```

---

#### 3. `LIST_FILES`

Retorna uma relação contendo os nomes de todos os arquivos gravados no diretório privado de dados do micro-app.

- **O que faz:** Lê a pasta `apps/{appId}/data`, filtra apenas as entradas que são arquivos físicos e devolve uma lista com seus nomes.
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "file",
  "action": "LIST_FILES",
  "params": {},
  "callbackId": "file_list_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "file_list_01",
  "module": "file",
  "type": "FILE_LIST",
  "success": true,
  "data": ["notas.txt", "dados_cache.json"]
}
```

---

#### 4. `PICK_FILE`

Abre a interface nativa do seletor de arquivos do sistema operacional (`@react-native-documents/picker`) para que o usuário escolha um arquivo do dispositivo.

- **O que faz:** Intercepta a seleção do usuário, cria uma cópia temporária segura dentro da pasta de cache privada do Helper, realiza a conversão do arquivo para uma string Data URI/Base64 e limpa a cópia temporária.
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "file",
  "action": "PICK_FILE",
  "params": {},
  "callbackId": "file_pick_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "file_pick_01",
  "module": "file",
  "type": "FILE_PICKED",
  "success": true,
  "data": {
    "name": "foto.jpg",
    "size": 1048576,
    "uri": "content://com.android.providers.media.documents/document/image%3A100",
    "type": "image/jpeg",
    "base64": "/9j/4AAQSkZJRgABAQAAAQABAAD..."
  }
}
```

---

#### 5. `IMPORT_PICKED_FILE`

Copia um arquivo armazenado na pasta de cache do aplicativo (gerado previamente pelo `PICK_FILE`) diretamente para o diretório permanente de dados (`data/`) do micro-app.

- **O que faz:** Valida se a URI de origem pertence estritamente ao `CachesDirectoryPath` do aplicativo e executa a cópia do arquivo para o sandbox permanente do módulo com o novo nome fornecido.
- **Parâmetros Esperados (`params`):**
- `sourceUri` _(String, Obrigatório)_: Caminho ou URI local do arquivo no cache.
- `fileName` _(String, Obrigatório)_: Nome de destino com o qual o arquivo será gravado no diretório de dados do módulo.

```json
// Envio
{
  "module": "file",
  "action": "IMPORT_PICKED_FILE",
  "params": {
    "sourceUri": "file:///data/user/0/com.helper/cache/picked_171000.jpg",
    "fileName": "imagem_importada.jpg"
  },
  "callbackId": "file_import_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "file_import_01",
  "module": "file",
  "type": "FILE_SUCCESS",
  "success": true,
  "message": "Arquivo importado com sucesso"
}
```

---

### Estrutura de Retorno em Caso de Cancelamento ou Erro

#### Cancelamento pelo Usuário no Seletor:

```json
{
  "callbackId": "file_pick_01",
  "module": "file",
  "type": "CANCELLED",
  "success": false,
  "error": "Seleção cancelada pelo usuário."
}
```

#### Erro de Validação ou Leitura:

```json
{
  "callbackId": "file_save_01",
  "module": "file",
  "type": "ERROR",
  "success": false,
  "error": "Nome de arquivo inválido."
}
```
