## 2.6 MicrophoneBridge (`mic`)

A `MicrophoneBridge` permite a captura de áudio do dispositivo através da biblioteca `react-native-audio-recorder-player`. Ela viabiliza a gravação local, conversão automática para Data URI/Base64 com suporte a MimeTypes dinâmicos de acordo com a plataforma (iOS/Android) e encerramento seguro de recursos.

---

### Proteções de Concorrência e Gerenciamento de Memória

1. **Prevenção de Condição de Corrida:** Utiliza a referência `isRecordingRef` para bloquear disparos simultâneos de gravação oriundos de cliques duplos rápidos ou chamadas sobrepostas dentro do micro-app.
2. **Sanitização de Caminhos:** O arquivo de áudio temporário gerado pelo sistema nativo tem seu prefixo `file://` removido antes da leitura via `RNFS.readFile`, garantindo compatibilidade multiplataforma durante o processo de codificação para Base64.
3. **Desativação em Desmontagem:** Um efeito de ciclo de vida (`useEffect`) garante que, caso o usuário saia da tela ou mude de módulo durante uma gravação ativa, o gravador nativo seja encerrado imediatamente, liberando o microfone do dispositivo.

---

### Ações Disponíveis (`actions`)

---

#### 1. `START_RECORDING`

Inicia a gravação de áudio através do microfone do dispositivo.

- **O que faz:** Solicita as permissões nativas de áudio no Android/iOS, valida se já não há uma gravação em andamento e inicia a captura nativa.
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "mic",
  "action": "START_RECORDING",
  "params": {},
  "callbackId": "mic_start_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "mic_start_01",
  "module": "mic",
  "type": "RECORDING_STARTED",
  "success": true,
  "uri": "file:///data/user/0/com.helper/cache/sound.mp4"
}
```

---

#### 2. `STOP_RECORDING`

Finaliza a gravação ativa, converte o arquivo de áudio gerado para Data URI/Base64 e o envia para a WebView.

- **O que faz:** Parilisa o gravador nativo, remove os listeners de eventos, lê o arquivo físico do disco e gera uma Data URI completa com MimeType apropriado (`audio/mp4` para Android ou `audio/m4a` para iOS).
- **Parâmetros Esperados (`params`):** Nenhum (objeto vazio `{}`).

```json
// Envio
{
  "module": "mic",
  "action": "STOP_RECORDING",
  "params": {},
  "callbackId": "mic_stop_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "mic_stop_01",
  "module": "mic",
  "type": "RECORDING_STOPPED",
  "success": true,
  "uri": "data:audio/mp4;base64,AAAAHGZ0eXBpc29tAAACAGlzb21pc28..."
}
```

---

### Estrutura de Retorno em Caso de Erro

Se o usuário negar a permissão no sistema operacional, tentar iniciar duas gravações consecutivas ou tentar parar uma gravação inexistente, a resposta será enviada no seguinte formato:

```json
{
  "callbackId": "mic_start_01",
  "module": "mic",
  "type": "ERROR",
  "success": false,
  "error": "Já existe uma gravação em andamento."
}
```
