## 2.3 LocationBridge (`location`)

A `LocationBridge` conecta os micro-apps ao serviço de geolocalização nativo do dispositivo utilizando a biblioteca `react-native-geolocation-service`. Ela permite obter a posição geográfica exata do usuário (coordenadas GPS) acompanhada de metadados de precisão, altitude, direção e velocidade.

---

### Funcionamento Interno e Tratamento do Sistema Operacional

1. **Gestão do Provedor Nativo:** No Android, o módulo solicita `ACCESS_FINE_LOCATION` com suporte à caixa de diálogo do sistema (`showLocationDialog: true`), forçando a ativação do GPS caso esteja desligado. No iOS, solicita autorização em tempo de uso (`whenInUse`).
2. **Tratamento de Assincronismo Seguro:** O método `getCurrentPosition` nativo opera via callbacks. A bridge encapsula essa chamada dentro de uma `Promise` explícita, garantindo que timeouts do GPS, falhas de sinal ou recusa de permissões caiam diretamente no bloco `catch` e retornem uma resposta estruturada para a WebView.
3. **Configuração Flexível de Precisão:** Permite que o micro-app ajuste parâmetros de consumo de energia e precisão da leitura (tempo limite, uso de cache e alta precisão via satélite).

---

### Ações Disponíveis (`actions`)

---

#### 1. `GET_CURRENT_LOCATION`

Captura a posição geográfica atual do dispositivo no momento da chamada.

- **O que faz:** Valida a permissão do sistema operacional, consulta o GPS/redes sem fio e devolve as coordenadas e dados de telemetria para a WebView.
- **Parâmetros Esperados (`params`):**
- `enableHighAccuracy` _(Boolean, Opcional)_: Se `true`, força o uso de GPS por satélite em vez de triangulação por Wi-Fi/celular. Padrão: `true`.
- `timeout` _(Number, Opcional)_: Tempo máximo de espera pela leitura em milissegundos. Padrão: `15000` (15 segundos).
- `maximumAge` _(Number, Opcional)_: Idade máxima aceitável para uma leitura em cache (em milissegundos). Padrão: `10000` (10 segundos).

```json
// Envio
{
  "module": "location",
  "action": "GET_CURRENT_LOCATION",
  "params": {
    "enableHighAccuracy": true,
    "timeout": 15000,
    "maximumAge": 10000
  },
  "callbackId": "loc_req_01"
}
```

- **Retorno em Caso de Sucesso (`sendToWebView`):**

```json
{
  "callbackId": "loc_req_01",
  "module": "location",
  "type": "LOCATION_DATA",
  "success": true,
  "data": {
    "latitude": -22.7253,
    "longitude": -47.6482,
    "accuracy": 5.2,
    "altitude": 540.8,
    "heading": 180.0,
    "speed": 0.0,
    "timestamp": 1710000000000
  }
}
```

---

### Estrutura de Retorno em Caso de Erro

Se o usuário recusar a permissão no sistema operacional, o sinal do GPS falhar ou ocorrer um estouro de tempo limite (timeout), a ponte retornará a seguinte mensagem:

```json
{
  "callbackId": "loc_req_01",
  "module": "location",
  "type": "ERROR",
  "success": false,
  "error": "Permissão de localização negada.",
  "code": 1
}
```
